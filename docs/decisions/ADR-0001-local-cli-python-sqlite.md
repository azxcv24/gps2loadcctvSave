# ADR-0001: 단일 사용자 로컬 CLI · Python 표준 라이브러리 · SQLite

- 상태: 제안
- 날짜: 2026-10-26
- 결정자: (저장소 소유자 승인 필요)

## 문맥

PLAN의 결정 후보 중 "단일 사용자용 로컬 도구와 서버형 운영 중 우선순위"가 정해지지 않았고, 저장소에는 언어·프레임워크가 없었다. M1(카탈로그·후보 시간 검색 MVP)은 외부 요청 없이 합성 데이터로 동작을 검증하는 단계다.

## 선택지

1. 서버형(웹 API + DB 서버): 여러 사용자·권한 분리에 유리하지만, 인증·키 관리·운영 보안 부담이 M1 범위를 크게 넘는다. 위치 이력이 서버에 모이는 위험도 생긴다.
2. 단일 사용자 로컬 CLI + 내장 DB: 자료가 사용자 기기를 벗어나지 않고, 의존성이 적어 검토가 쉽다.

## 결정

- 단일 사용자 로컬 CLI(`gps2cctv`)로 시작한다.
- Python 3.11 이상, **런타임 외부 의존성 없음**(표준 라이브러리만). 테스트에만 pytest를 쓴다.
- 저장소는 SQLite 파일 하나(기본 `data/gps2cctv.sqlite3`, 권한 0600, `secure_delete` 사용).

## 결과와 위험

- 의존성 공급망 위험과 설치 부담이 작다.
- 저장 시 암호화는 아직 없다(M3). DB 파일 보호는 OS 계정 권한에 의존한다. README에 명시한다.
- 여러 사용자·기관 운영으로 확장하려면 권한 분리·키 관리를 포함한 재설계가 필요하다.

## 재검토 조건

- 실제 사용자가 2명 이상이거나 기관 운영이 필요해질 때
- M3(제한적 자료 보존)에서 암호화 저장 방식을 정할 때
